## Нюанс с иконками
В проекте для иконок логотипов инструментов использовалось api сайта [api.iconify.design](https://api.iconify.design), оттуда получилось доставать только чёрно-белые иконки. Также не все иконки из шаблона можно получить с этого api, поэтому microsoft365copilot и midjourney были заменены на другую ближайшую(open)

## Чтобы развернуть локально нужно:
 1. Установка зависимостей: `npm install`
 2. Запуск: 
    - В режиме разработки: `npm run dev`
    - В обычном режиме: `npm run build && npm run preview`
